# Roadmap and Backlog

## P0 — Foundations
Auth, profiles, consent, report upload, extraction review, canonical observations, provenance, report list.

## P1 — Trustworthy analysis
Comparable report selection, report analysis, multi-marker rule engine, trends, test coverage, organ evidence.

## P2 — AI MVP
Context manifest, five read-only tools, orchestrator, session state, citations, chart cards, evaluation suite.

## P3 — Engagement and family
Email invitations, scoped family access, condition views, lifestyle plans, check-ins, notifications.

## P4 — Connected data and scale
Device connectors, advanced retrieval, personalized insights, caching, operational maturity and more locales.

## Prioritization rule
Never ship a chat feature that bypasses missing data-quality, authorization or clinical-safety foundations.

## Definition of done
Acceptance tests, security tests, accessible UI, telemetry, documentation, rollback plan and source-linked demo walkthrough.
