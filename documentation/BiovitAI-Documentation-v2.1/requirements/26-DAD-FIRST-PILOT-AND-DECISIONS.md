# Dad-First Pilot and Product Decisions

## Pilot objective
Validate whether an older adult and a trusted family caregiver can safely upload reports, understand historical changes and ask useful questions without confusion.

## Suggested pilot
Start with synthetic reports, then opt-in real records only after security, consent and safety reviews. Use a small set of diverse report formats and representative historical comparisons.

## Tasks
Upload a report; verify one extracted value; compare two reports; locate a source page; inspect an organ evidence view; ask an AI follow-up; invite a caregiver; revoke access.

## Research questions
Do users understand "not assessed"? Do they confuse a reference-range flag with a diagnosis? Can they distinguish the report date from upload date? Do they know which profile is active? Does the chat give useful, cited answers?

## Decision log
Choose target market, supported languages, initial biomarkers, mobile stack, hosting region, clinical review process, device integrations, and consent model before implementation freeze.
