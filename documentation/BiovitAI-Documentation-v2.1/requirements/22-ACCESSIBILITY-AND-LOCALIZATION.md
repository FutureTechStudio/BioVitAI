# Accessibility and Localization

## Requirements
WCAG-aligned navigation and contrast, screen reader labels, keyboard support, scalable text, large touch targets, reduced-motion support, readable dates/units and clear language.

## Body map
Provide an equivalent accessible organ list. Never rely on color alone. Tooltips must work without hover.

## Chat
Announce streaming completion accessibly, preserve focus after new cards, label source buttons, provide transcript export, avoid infinite auto-scroll when reading history.

## Localization
Use locale-aware dates, number formatting, timezones and units. Do not translate clinical units or standardized codes without a validated mapping. Maintain glossary for translated medical terms.

## Older-adult usability
Short tasks, explicit confirmation, large controls, clear error recovery, minimal jargon and optional caregiver assistance.
