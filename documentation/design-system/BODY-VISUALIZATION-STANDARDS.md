# Body visualization standards

Use a full-body, front-facing, gender-neutral silhouette with no internal organ artwork. Shared vector geometry provides the same proportions across web and native rendering. Organ icons belong in the evidence cards.

The current body is neutral. Display “Wellness goal progress — Not yet available” because there is no validated goal-progress service. A future fill level must represent a named, validated wellness target; 100% means target completion, never perfect health. Do not calculate a score from biomarkers, organ status or missing data.

Heart, liver, kidneys, thyroid and metabolic pointers navigate the existing evidence categories. Their neutral status reflects the server's inactive interpretation rules. Pointer placement is an interface affordance, not a diagnosis. Provide keyboard/touch-accessible equivalent cards and explain absent interpretation in the detail view.

Do not associate individual tests with organs through an unreviewed client-side clinical mapping. Source measurements remain available in Insights with their own provenance.
