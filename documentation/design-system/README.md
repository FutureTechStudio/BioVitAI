# BiovitAI BioFlow

BioFlow is the permanent presentation system for the web and Expo applications. The approved dashboard reference and the owner's complete-migration brief establish the visual direction. Existing APIs, verified evidence, permissions and consent remain authoritative.

Read the principles, colors/typography, component standards, layout, body visualization, accessibility and quality checklist in this directory. Register every new route, rendered component and significant workflow state in `UI-MIGRATION-COVERAGE.json`, then regenerate its Markdown view with `node tools/bioflow-coverage.mjs`.

The inventory distinguishes engineering migration from functional, visual, responsive and accessibility validation. Planned services are not migrated features. Formal approvals and human validation are not inferred from automated checks.

The original application is checkpointed at `ced0d80bfe70d81258acadf63eca85b06fb2a9ba` on GitHub before this work. Implementation is on `codex/bioflow-ui`.

Read [the validation report](VALIDATION-REPORT.md) for executed checks, module statuses, screenshots, measurements and unresolved acceptance limits. The coverage matrix records source migration and each validation dimension separately.
