# Layout and responsiveness

Desktop uses the persistent sidebar, compact topbar and two-column dashboard. Below 1200px the dashboard stacks and navigation narrows. Below 768px web navigation uses a modal drawer; filters wrap and content stacks. Preserve evidence actions and labels rather than clipping them. Source documents and wide evidence tables may pan within their own bounded containers; the page must not overflow horizontally.

Android keeps My Health, My Wellness and Community & Trends bottom tabs. Reports and Insights are stack screens; the original report-detail, profiles, authentication and chat destinations remain valid. Preserve safe areas, keyboard avoidance and back behavior.

Use logical CSS properties and direction-neutral icons where appropriate. English is delivered; RTL and large-text layout checks are recorded independently from Arabic translation. Reduce optional decoration before reducing information readability.
