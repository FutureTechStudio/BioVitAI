# BioFlow quality checklist

- Register route, significant components and associated states before claiming coverage.
- Confirm tokens, typography, card/control geometry and shared shell against the approved reference.
- Preserve original route entry points, form validation, revisions, provenance and authorization.
- Exercise populated, loading, empty, error, disabled, unavailable and access-loss states.
- Verify keyboard focus, modal exit/return, labels, contrast and chart text alternatives.
- Check desktop, tablet, mobile, large text, RTL layout and reduced motion.
- Check Android rendering, source preview, back handling and keyboard avoidance.
- Run applicable regression, type, lint, build and coverage/token checks.
- Record screenshots and exact commands/results; distinguish automated checks from human assessment.
- Leave blocked or unexecuted validation pending; never infer completion from shared CSS alone.
